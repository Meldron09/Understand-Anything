# Local rendering with tiered dependencies and per-unit degradation

Plugins cannot declare or install binaries, and no renderer has a verified restricted-sandbox story, so all rendering runs on the learner's machine via Bash and the plugin makes no sandbox promise (each renderer reference file carries a headless-sandbox yes/no/unknown flag). Needs are grouped into dependency tiers: 0 none (text, interactive HTML, quiz, and slides as a Marp `.md` deck, with an optional render to HTML when `marp` or `npx` exists and to PDF when Chrome exists), 1 `uv` (which provisions Python for `pypdf`, trafilatura and kokoro-onnx), 2 plus ffmpeg, cairo and pkg-config (Manim CE with Typst), 3 opt-in Node 22+ and Chromium (HyperFrames; no Blender in v1, see ADR 0005). `uv` is the only hard bootstrap for the default video path, LaTeX is never required, and poppler is soft.

An on-demand preflight script (no SessionStart hook, no cache) reports tiers and capability probes such as ffmpeg's `subtitles` filter, a headless Chromium (which upgrades `verify-html` from grep rules to a DOM check), `marp`/`npx`, and cairo/pkg-config; intake annotates unavailable modes with what they need, and each renderer re-runs it before rendering. The plugin never installs system tools (it prints the command, the learner runs it). It may provision pinned Python tooling into an isolated `uv` environment under `${CLAUDE_PLUGIN_DATA}` (never the plugin directory, which is replaced on every version, nor the lesson folder) after one consent per lesson that states download size; scripts receive it as `--data-dir` because the variable is substituted in `SKILL.md` text but absent from the Bash environment. Node renderers are off by default and opt-in with telemetry off and frame streaming on.

Degradation is per lesson unit: picked renderer, its fallback renderer, then silent video plus a narration script when TTS is missing, then a non-video mode when ffmpeg is missing, with text as the floor. A failure predicted at plan time is offered to the learner once (install or downgrade); a failure at render time falls back automatically, keeps partial files, is announced, and is recorded as `degraded: <reason>` on the unit. There is no retry beyond the fallback renderer.

Rejected: a SessionStart hook (taxes text-only sessions), auto-installing system tools (surprising side effects, brew prompts), whole-lesson degradation (loses working units).
