# Interview protocol

- One question at a time, each with a recommended answer; wait for the answer before the next.
- Look facts up instead of asking the learner.
- Stop when the brief's fields are filled.
- "You pick" takes the recommended answer.
- Closed sets (depth, budget, mode) use `AskUserQuestion` with the recommended option first; the goal and why are plain chat. If `AskUserQuestion` is unavailable, ask in plain text.
