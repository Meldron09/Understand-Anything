Initializing projects

A project is a directory with a pyproject.toml file that records its metadata and dependencies. Creating one with uv takes a single command, and the generated layout is deliberately small so that you can read every file it produces without opening a tutorial first.

Creating an application

Applications and libraries differ in how they are packaged. An application is run by name from the command line and is not normally published, while a library is built into a wheel and uploaded to an index so that other projects can depend on it.

$ uv init example
Initialized project `example` at `/home/user/example`
$ cd example
$ ls
main.py  pyproject.toml  README.md

Creating a library

Pass the lib flag to get a src layout with a package directory, which keeps imports honest because the package is only importable once it has been installed into the environment.

$ uv init --lib example-lib
$ tree example-lib
example-lib
|-- pyproject.toml
`-- src/example_lib/__init__.py

Adding a dependency

Dependencies are added with uv add, which edits pyproject.toml and updates the lockfile in one step so the two never drift apart.

$ uv add requests
Resolved 5 packages in 120ms
Installed 5 packages in 8ms
